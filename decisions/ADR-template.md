# ADR-XXX：一句话标题

```text
日期:
状态: 提议 | 已接受 | 已废弃
关联 run / case:

决策:
（写做了什么取舍，不写背景铺陈）

当时的约束:
（规模、系统、能力、时间窗。换掉这些，结论可能不成立）

考虑过的其他选项:
（每条附一句为什么没选）

依据:
（引用 cases/ 或 docs/ 里的 L2 及以上主张，带可证伪条件）

预期效果与验证方式:
（可观察的行为变化，不是"更清晰"）

推翻条件:
（什么信号出现时应当重新审议这条决策）

已知局限:
```

## 规则

- 追加，不回改。结论变了就写一条新的 ADR 并在旧条目里加"已被 ADR-YYY 取代"。
- 一条 ADR 只记一个决策。
- 不记录会议过程，只记录取舍与依据。
- 依据不足时标"提议"，不要伪装成"已接受"。
